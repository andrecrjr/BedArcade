# Extension Project Instructions

- Follow the repository instructions in `../AGENTS.md`.
- This directory is the complete browser extension project; keep its source, tests, assets, configuration, dependencies, and generated WXT files here.
- Use `npm install`, `npm run dev`, `npm run build`, `npm run typecheck`, `npm run lint`, and `npm run format` from this directory.
- The extension name and product branding are Gamepad Desktop.
